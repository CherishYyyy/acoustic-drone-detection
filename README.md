# 基于声学信号的无人机探测系统

## 📖 项目简介
本项目旨在通过声学信号处理与深度学习技术，解决低空无人机探测问题。利用公开数据集，提取声音的梅尔频率倒谱系数（MFCC）特征，对比了传统机器学习（随机森林）与深度学习（CNN）在二分类任务（无人机 vs 噪音）上的表现，并完成了从模型训练到单音频推理部署的全流程闭环。

## 📁 数据集
*   **来源**：DroneAudioDataset（开源数据集）
*   **总样本量**：11702 个有效样本（已过滤极短音频）
*   **类别**：噪音(标签0)、无人机(标签1)

## 🧠 模型对比与实验结果

| 模型 | 特征提取方式 | 准确率 | 漏报数(将无人机误判为噪音) | 备注 |
| :--- | :--- | :--- | :--- | :--- |
| 随机森林 (Baseline) | MFCC平均值 (13维) | 97.64% | 80 | 丢弃了时间维度，导致弱信号漏报严重 |
| **CNN (进阶模型)** | MFCC矩阵 (13x40) | **99.94%** | **1** | **保留了时间周期性，大幅降低漏报率** |

> **结论**：在声学反无人机任务中，保留时序特征的 CNN 模型显著优于基于均值特征的随机森林模型，证明了捕捉声音时间序列规律对微弱信号探测的重要性。

⚠️ 工程踩坑与解决记录
问题：在跨电脑迁移代码时，出现 OSError: [WinError 1114] 动态链接库(DLL)初始化例程失败。

原因：Windows 系统缺少 PyTorch 底层所需的 C++ 运行库，且全局 Python 环境存在包冲突。

解决方案：

运行 winget install Microsoft.VCRedist.2015+.x64 安装微软运行库。
使用 python -m venv myenv 建立隔离的虚拟环境，避免全局环境污染。
重新安装 CPU 版本 PyTorch，彻底解决 DLL 加载失败问题。
